# Version 1.0.0

Released: 2026-10-09

Commit range: `37be45e..HEAD`

## Major changes

- Initial release of Markit Editor: a Typora-style live preview Markdown editor built on CodeMirror 6, opened as a dedicated tab alongside the default editor.
- Live rendering of headings, emphasis, links, lists, task lists, quotes, code blocks, images and tables; the markdown of the element under the caret is revealed for editing.
- Mermaid diagrams rendered inline, with an enlarged view-only popup.
- Reading-optimised typography (NV Palatium body text, Geist Mono for code).
- Bi-directional sync with the standard IntelliJ editor and automatic Light/Dark theme support.

## Tooling

- Added a GitHub Actions workflow that builds, signs, publishes to the JetBrains Marketplace, and cuts a `v<version>` GitHub release on every push to `main` that changes `pluginVersion`; documented the versioning and channel rules in `RELEASE_GUIDELINE.md`.
