# Version 1.0.1

Released: 2026-10-10

Commit range: `fe3d016..HEAD`

## Fixes

- The mouse pointer now shows a text cursor over the document, and a hand over images, checkboxes and diagrams. The off-screen JCEF browser never forwards Chromium's cursor changes, so the page now reports its cursor to the IDE.
- Fixed clicks on the lower part of a heading selecting the next line in documents containing tables or Mermaid diagrams. Those block widgets used CSS margins, which CodeMirror's height map ignores; they now use padding.
