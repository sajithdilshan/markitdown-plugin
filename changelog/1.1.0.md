# Version 1.1.0

Released: 2026-11-21

Commit range: `9e979fb..HEAD`

## Fixes

- Selecting text inside a code block, table, heading or quote now keeps its markdown source revealed. Previously only a caret revealed syntax, so the block snapped back to the rendered view on mouse-up.
- Selected text is now highlighted inside code blocks, inline code and table source. CodeMirror draws the selection behind the text, where those opaque backgrounds hid it; selected text is now also marked directly.

## Maintenance

- Replaced the deprecated single-argument `Document.addDocumentListener` and `UIUtil.isUnderDarcula()` with their supported alternatives.
- Updated dependencies to the latest stable releases: Gradle 9.9.2, Kotlin Gradle plugin 2.4.21, IntelliJ Platform Gradle plugin 2.20.1, Mermaid 12.3.0, esbuild 0.28.2, CodeMirror view 6.43.15, and the publish workflow's GitHub Actions.
